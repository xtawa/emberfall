EMBERFALL is a top-down arena survival game: you are a lone lantern-wisp in the dark, and your only attack is a dash — dash through shades to set them alight, chain ignitions into combos, gather the embers, choose an upgrade after each wave, and survive all ten waves to face the Gloom Herald.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
